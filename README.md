# HTML Learning Lab

A practical learning repository focused on building a strong foundation in **HTML (HyperText Markup Language)** through structured lessons, hands-on coding, and practical examples.

This repository documents my HTML learning journey, covering essential concepts and their implementation through individual practice files.

## Topics Covered

- HTML Document Structure
- Headings, Paragraphs & Text Formatting
- Links & Images
- Lists & Tables
- HTML Forms & Input Elements
- Semantic HTML
- HTML Entities & Special Characters
- Audio & Video
- Iframes & Embedded Content
- HTML Attributes
- Responsive Images
- Meta Tags & SEO Basics
- Accessibility Fundamentals
- HTML5 Elements & Features
