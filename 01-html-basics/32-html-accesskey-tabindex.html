HTML Accesskey and Tabindex

Learning keyboard navigation and shortcuts in HTML.

1. Tabindex Attribute

This paragraph can receive keyboard focus.

Press the Tab key to move through focusable elements.

2. Accesskey Attribute



Access keys can focus or activate elements using browser and operating-system-specific key combinations.

3. Keyboard Navigation Tips

  • Use Tab to move forward through focusable elements.
  • Use Shift + Tab to move backward.
  • Use Enter or Space to activate many focused controls.
  • Prefer the natural tab order in most webpages.
