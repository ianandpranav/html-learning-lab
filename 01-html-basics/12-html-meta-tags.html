HTML Meta Tags

Learning how to provide metadata about an HTML document.

What Are Meta Tags?

Meta tags provide information about a webpage. They are placed inside the head element and are generally not displayed as page content.

Important Meta Tags

  • charset: Defines the character encoding of the document.
  • viewport: Helps the page adapt to mobile screen sizes.
  • description: Provides a summary that search engines may use.
  • author: Identifies the author or content creator.
  • robots: Gives search engine crawlers indexing instructions.
