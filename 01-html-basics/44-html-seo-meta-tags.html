Learning how metadata describes a webpage.

What is Metadata?

Metadata provides information about a webpage. It is generally written inside the head element.

Important Meta Tags

  • Charset defines character encoding.
  • Viewport helps control mobile page dimensions.
  • Description summarizes the webpage.
  • Author identifies the content creator.
  • Robots gives crawling and indexing instructions.
  • Open Graph metadata helps control social link previews.

Important Note

Meta keywords are generally ignored by major search engines. A meta description can help describe a page in search results, but it does not guarantee a particular ranking or snippet.
