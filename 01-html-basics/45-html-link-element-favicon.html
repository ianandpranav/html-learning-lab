HTML Link Element

Learning how to connect external resources to a webpage.

1. External CSS

The stylesheet link connects an external CSS file to the HTML document. 

<link rel="stylesheet" href="styles.css">

2. Favicon

A favicon is a small icon displayed in the browser tab. 

<link rel="icon" href="favicon.png">

3. Canonical Link

A canonical link indicates the preferred URL for a webpage.

4. Alternate Link

An alternate link can identify another version of a webpage, such as a translated version.
