2. Relative Image

The image URL resolves relative to the base URL.

3. Base Target

Relative links without their own target attribute use the target defined in the base element.

Important Notes

  • The base element is placed inside the head element.
  • A document should have at most one base element.
  • The href attribute defines the base URL.
  • The target attribute defines the default link target.
  • Be careful: base can affect all relative URLs in the document.
