HTML Iframes

Learning how to embed external content in a webpage.

What Is an Iframe?

An iframe embeds another webpage or supported content inside the current HTML document.

Iframe Example

Important Attributes

  • src: Specifies the embedded page URL.
  • title: Describes the iframe for accessibility.
  • width: Sets the iframe width.
  • height: Sets the iframe height.
  • loading="lazy": Delays loading until needed.
