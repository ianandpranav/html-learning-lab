HTML Escape Characters and Entities

Learning how to display reserved characters and special symbols.

1. Reserved Characters

Less than symbol: <

Greater than symbol: >

Ampersand symbol: &

Double quotation mark: "

Single quotation mark: '

2. Display HTML Tags as Text

To display a paragraph tag, write:

<p>Hello World</p>

To display a heading tag, write:

<h1>My Heading</h1>

3. Special Symbols

Copyright: ©

Registered trademark: ®

Trademark: ™

Rupee: ₹

Euro: €

Degree: °

Multiplication: ×

Division: ÷

4. Non-Breaking Space

HTML Learning Lab

A non-breaking space helps keep words together without allowing a line break at that space.

5. Common HTML Entities

  • &lt; displays <
  • &gt; displays >
  • &amp; displays &
  • &copy; displays ©
  • &nbsp; represents a non-breaking space
